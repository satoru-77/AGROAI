AGROAI: Tomato Leaf Disease Classification
A full-stack web application designed to help farmers and enthusiasts quickly diagnose common diseases in tomato leaves using advanced deep learning technology.

**Clone the REPO**

git clone https://github.com/satoru-77/AGROAI.git
cd AGROAI

Backend Setup & Run:

# Navigate to the backend directory
cd backend

# Create and activate a Python virtual environment (recommended)
python -m venv myenv
source myenv/Scripts/activate  # Use 'source myenv/bin/activate' on Linux/macOS

# Install Python dependencies
pip install -r requirements.txt
